# Tyler Flar

[Jackdaw](https://github.com/TylerFlar/jackdaw-balatro) is a bit-exact Balatro simulator for reinforcement learning. I spent summer 2026 at Brightree (a ResMed company) building a docs-as-code toolchain for its customer-facing API, and before that researched autonomous surgical robotics at the [Advanced Robotics and Controls Lab](https://ucsdarclab.com/).

Projects, classes, and a full CV live at [tylerflar.com](https://tylerflar.com).
